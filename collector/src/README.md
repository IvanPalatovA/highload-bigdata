# Переменные окружения сборщика (Вариант 93 — GH Archive)

| Переменная | По умолчанию | Назначение |
|---|---|---|
| `COLLECTOR_USER_AGENT` | `mephi-bigdata-collector-v93/1.0 (palatov.vanya@gmail.com)` | Заголовок `User-Agent` с контактом для HTTP-запросов |
| `COLLECTOR_POLL_SECONDS` | `60` | Период проверки появления нового часового архива (в секундах) |
| `COLLECTOR_HISTORY_FROM` | `8 дней назад` | Начальная дата исторического среза (`YYYY-MM-DD`, UTC) |
| `COLLECTOR_HISTORY_TO` | `2 дня назад` | Конечная дата исторического среза (`YYYY-MM-DD`, UTC) |
| `COLLECTOR_MAX_EVENTS_PER_HOUR` | `0` (без лимита) | Ограничение числа просматриваемых событий из архива часа при потоковом чтении |
| `COLLECTOR_LAKE_PREFIX` | `""` | Префикс в объектном хранилище S3 (используется начиная с ЛР3) |
